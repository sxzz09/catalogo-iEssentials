# iEssentials Catalog

A high-performance digital product catalog and order generator designed for **iEssentials**. Built with **Next.js**, **TypeScript**, and **Tailwind CSS**, featuring real-time BCV currency conversion, dual retail/wholesale pricing models, and instant PNG receipt exports.

## ⚡ Key Features

- **Dual Operating Modes:** Toggle between "Detal" and "Al Mayor" pricing seamlessly.
- **Dynamic Currency Conversion:** Automatic subtotal calculations in USD and Bolívares (VES) based on official BCV Euro rates.
- **Instant Receipt Generation:** Export pixel-perfect printable order summaries as PNG images directly from the browser.
- **Direct WhatsApp Dispatch:** One-click order formatting sent straight to customer service via WhatsApp.
- **Minimum Order Quantity Rules:** Enforced product thresholds specifically tuned for wholesale purchases.

## Compiling

Clone the repository and install dependencies to run the development server locally:

```bash
# Clone the repository
git clone [https://github.com/your-username/iessentials-catalog.git](https://github.com/your-username/iessentials-catalog.git)

# Navigate to project root
cd iessentials-catalog

# Install dependencies
npm install

# Run development server
npm run dev

Open on your browser: http://localhost:3000
```
